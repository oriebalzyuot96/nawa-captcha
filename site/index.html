Nawa Captcha — the self-hosted, accessible puzzle CAPTCHA

An open-source reCAPTCHA, hCaptcha and Turnstile alternative with 38 puzzle types. Your own server issues the puzzle and verifies the answer — no third-party tracking, no cookies, no data leaving your app. Works with React, Vue, Svelte, Angular or plain HTML, and verifies on Node.js or ASP.NET Core.

    A CAPTCHA that looks like part of your product
    
        
    A layered, glass-like card with real depth: a subtle perspective tilt that follows the pointer, parallax inside the puzzle frame, pieces that lift and click into place, and a verified state that draws its own checkmark. Six themes in light and dark plus high contrast, or let it pick up your Pelagic UI tokens automatically. Motion switches off for prefers-reduced-motion, every colour pair passes WCAG 2.2 AA, and forced colours are respected.
    
        
    
          
          
          
        
    
        
    
          
    🔊 Optional sound
    Soft synthesized cues for grab, snap, step and success (Web Audio, no files). Off by default, never before a click or key press, with a volume slider, a remembered speaker toggle and an app-level mute. Every change is also announced to screen readers.
    
          
    🎧 Audio challenge
    For blind and low-vision visitors: a server-synthesized WAV of spoken digits (or beeps to count) over background noise, with a replay limit and no transcript. The answer stays sealed on the server like every other puzzle.
    
          
    🎨 Themes and tokens
    theme="pelagic|midnight|aurora|sand|ocean|mono", appearance="auto|light|dark|high-contrast", --nawa-captcha-* overrides, and automatic Pelagic UI --pl-* tokens (legacy --nw-* still work).
    
        
    
      
    
    
    

    
    
      
    
        
    38 puzzle types
    
        
    Every type works with mouse, touch and keyboard, and the text alternative is always one click away. The answer never reaches the browser: pictures are rendered on the server, and the solution is sealed inside the challenge token. "Blind guess" is the chance that a random answer passes one attempt; combine weak types with others (steps) or keep them for low-risk forms.

    Why Nawa Captcha
    
        
    
          
    🔒 The client is never trusted
    Puzzles are rendered on the server. The answer is sealed with AES-256-GCM inside the challenge and never reaches the browser.
    
          
    ✅ Verify on your backend
    A solved puzzle yields a short-lived, single-use, signed pass token. Your route verifies it locally — like reCAPTCHA's siteverify, without the third party.
    
          
    ♿ Everyone can pass it
    Mouse, touch and full keyboard for every puzzle, plus a text alternative with 50+ question templates and an audio challenge for screen-reader users (WCAG 1.1.1, 2.1.1). Arabic and English, RTL.
    
          
    🧩 30+ challenge types, your choice
    Allow one, two or many types, per action. Pick at random, in sequence or by an adaptive difficulty ladder, and chain two or three puzzles before a pass token.
    
          
    🛡️ Replay & tamper proof
    Single-use tokens, expiry, IP/UA binding, key rotation with key IDs, pointer-trajectory heuristics and rate-limit hooks.
    
          
    📦 Zero dependencies
    The Node server uses only node:crypto and node:zlib. The widget is a dependency-free Web Component that runs under a strict CSP.
    
        
    
      
    
    
    

    
    
      
    
        
    Install
    
        
    Coming to npm and NuGet. The packages are published under the @nawa-captcha scope (and NawaCaptcha.AspNetCore) once the organisation is set up. Until then, build them from source:
          
    git clone https://github.com/oriebalzyuot96/nawa-captcha.git
cd nawa-captcha && npm install && npm run build
npm pack -w @nawa-captcha/server -w @nawa-captcha/widget   # → .tgz files you can npm install
    
        
    When published, npm, yarn, pnpm and bun all work:
    
        
    npm i @nawa-captcha/server @nawa-captcha/widget
yarn add @nawa-captcha/react      # or @nawa-captcha/vue, @nawa-captcha/svelte, @nawa-captcha/angular
dotnet add package NawaCaptcha.AspNetCore
    
        
    Server (Express) — choose your puzzles:
    
        
    import { createNawaCaptcha } from '@nawa-captcha/server';
import { nawaCaptchaExpress, requireCaptcha } from '@nawa-captcha/server/express';

const guard = createNawaCaptcha({
  secret: process.env.NAWA_CAPTCHA_SECRET,
  types: ['slider', 'rotate-object', 'pairs', 'maze'],   // one, two or many
  mode: 'random',                                         // or 'sequence' | 'adaptive'
  perAction: { login: ['pow', 'slider'], signup: { types: ['maze', 'pairs'], steps: 2 } },
});
app.use('/captcha', express.json({ limit: '32kb' }), nawaCaptchaExpress(guard));
app.post('/login', requireCaptcha(guard, { expectedAction: 'login', maxAgeSec: 300 }), handler);
    
        
    Browser (any framework) — types can only narrow the server's list:
    
        
    <nawa-captcha site-key="main" endpoint="/captcha" action="login" types="slider,rotate-object"></nawa-captcha>
    
        
    ASP.NET Core:
    
        
    builder.Services.AddNawaCaptcha(builder.Configuration.GetSection("NawaCaptcha"));
app.MapPost("/api/contact", Handler).RequireNawaCaptcha("contact");

    نوى كابتشا — كابتشا ألغاز مستضافة ذاتياً وسهلة الوصول
    
        
    بديل مفتوح المصدر لـ reCAPTCHA: خادمك يُنشئ اللغز ويتحقق من الحل، دون تتبّع أو أطراف ثالثة. أكثر من ثلاثين نوعًا من الألغاز تختار منها ما تشاء، لغزًا واحدًا أو عدة ألغاز، لكل إجراء على حدة، مع إمكانية طلب لغزين متتاليين. دعم كامل للوحة المفاتيح وقارئات الشاشة مع سؤال نصي وتحدٍّ صوتي، والعربية والإنجليزية مع RTL، وستة أنماط ألوان بتصميم ثلاثي الأبعاد. يعمل مع React وVue وSvelte وAngular ويتحقق عبر Node.js أو ASP.NET Core. جرّب الملعب التفاعلي أعلاه باللغة العربية.
