Nawa Guard — the self-hosted, accessible puzzle CAPTCHA

An open-source reCAPTCHA, hCaptcha and Turnstile alternative. Your own server issues the puzzle and verifies the answer — no third-party tracking, no cookies, no data leaving your app. Works with React, Vue, Svelte, Angular or plain HTML, and verifies on Node.js or ASP.NET Core.

Get started Star on GitHub

Why Nawa Guard

🔒 The client is never trusted

Puzzles are rendered on the server. The answer is sealed with AES-256-GCM inside the challenge and never reaches the browser.

✅ Verify on your backend

A solved puzzle yields a short-lived, single-use, signed pass token. Your route verifies it locally — like reCAPTCHA's siteverify, without the third party.

♿ Everyone can pass it

Mouse, touch and full keyboard for every puzzle, plus a text alternative for screen-reader users (WCAG 1.1.1, 2.1.1). Arabic and English, RTL.

🧩 8 challenge types

Slider jigsaw, rotate, pick icons, math image, drag to order, connect the dots, invisible proof-of-work and an accessible question. Difficulty adapts after failures.

🛡️ Replay & tamper proof

Single-use tokens, expiry, IP/UA binding, key rotation with key IDs, pointer-trajectory heuristics and rate-limit hooks.

📦 Zero dependencies

The Node server uses only node:crypto and node:zlib. The widget is a dependency-free Web Component that runs under a strict CSP.

Install

npm, yarn, pnpm and bun all work:

npm i @nawa-guard/server @nawa-guard/widget
yarn add @nawa-guard/react      # or @nawa-guard/vue, @nawa-guard/svelte, @nawa-guard/angular
dotnet add package NawaGuard.AspNetCore

Server (Express):

import { createNawaGuard } from '@nawa-guard/server';
import { nawaGuardExpress, requireCaptcha } from '@nawa-guard/server/express';

const guard = createNawaGuard({ secret: process.env.NAWA_GUARD_SECRET, siteKeys: ['main'], actions: ['login'] });
app.use('/captcha', express.json({ limit: '32kb' }), nawaGuardExpress(guard));
app.post('/login', requireCaptcha(guard, { expectedAction: 'login', maxAgeSec: 300 }), handler);

Browser (any framework):

<nawa-guard site-key="main" endpoint="/captcha" action="login" lang="en"></nawa-guard>

ASP.NET Core:

builder.Services.AddNawaGuard(builder.Configuration.GetSection("NawaGuard"));
app.MapPost("/api/contact", Handler).RequireNawaGuard("contact");
